# Équipements Recommandés

Le combat contre les Thargoids requiert un équipement très spécialisé. En effet, les Thargoids possèdent des résistances uniques et infligent des types de dégâts inhabituels qui rendent les vaisseaux de combat standards inefficaces.

Nous avons compilé les recommandations suivantes pour vous guider dans le choix et la configuration du vaisseau le plus adapté à votre style de jeu. Ces configurations ont été conçues pour équilibrer puissance de feu et survivabilité, tout en restant indulgentes face aux erreurs de pilotage.

::: info Théorie de l'Équipement
Pour une explication approfondie sur la logique de conception de nos vaisseaux AX, consultez notre page [Théorie de l'Équipement](/fr/shipbuildtheory).
:::

## Types de Configurations

On distingue principalement deux grands types de combat Thargoid : contre les [Éclaireurs](/fr/scouts) (Scouts) et contre les [Intercepteurs](/fr/interceptors). Leurs mécaniques étant radicalement différentes, les configurations requises le sont aussi.

---

# Contre les Intercepteurs

Les Intercepteurs Thargoids sont de redoutables adversaires. En raison des dégâts colossaux qu'ils infligent, trois grands styles de combat se distinguent :

- **Vaisseaux Rapides avec Boucliers (Hybrides Entrelacés)** : Rapides avec des boucliers Bi-Weave à régénération rapide (Recommandé débutants).
- **Vaisseaux Rapides sans Boucliers (Orbiteurs Froids)** : Vaisseaux sans bouclier utilisant la gestion thermique et l'orbite froide pour esquiver les tirs (Intermédiaire/Méta).
- **Vaisseaux Lourds avec Boucliers (Shield Tanks)** : Vaisseaux massifs avec boucliers prismatiques géants qui réinitialisent leurs boucliers (Avancé).
