# Рекомендованные сборки

Охота на таргоидов требует специализированного оснащения, поскольку таргоиды обладают колоссальным сопротивлением к стандартному человеческому вооружению и наносят специфические типы урона.

Мы собрали проверенные рекомендации, которые помогут вам выбрать и собрать максимально эффективный корабль для борьбы с таргоидами. Эти конфигурации обеспечивают баланс между сокрушительной огневой мощью и выживаемостью, прощая ошибки пилотирования.

::: info Теория сборки кораблей
Для подробного ознакомления с логикой выбора модулей и вооружения посетите страницу [Теория сборки AX-корабля](/ru/shipbuildtheory).
:::

## Основные типы сборок

Существует два принципиально разных направления борьбы: охота на **разведчиков (Scouts)** и бой с **перехватчиками (Interceptors)**. Их механики сильно различаются, поэтому для каждого класса требуются свои корабли.

---

# Сборки против перехватчиков

Таргоидские перехватчики наносят колоссальный урон. В AX-боях выделились три основных стиля:

- **Быстрые гибридные сборки со щитом (Bi-Weave)**: корабли с двухпоточными щитами быстрого восстановления (для новичков).
- **Быстрые сборки без щита (Холодная орбита)**: мета-корабли, использующие нагрев ниже 20% для уклонения от огня (рекомендуется для всех).
- **Тяжелые бронированные корабли (Shield Tanks)**: исполины с гигантскими призматическими щитами (для опытных пилотов).
